# Подход

Личный нативный трекер силовых тренировок для iPhone. SwiftUI, iOS 17+, без сервера и сторонних зависимостей.

## Запуск на своём iPhone

Чтобы поставить новую версию с изменениями на iPhone (Anna), используй [инструкцию по установке новой сборки](INSTALL_UPDATE_RU.md).

1. Открой `Podhod.xcodeproj` в Xcode.
2. Подключи разблокированный iPhone к Mac кабелем. Подтверди «Доверять этому компьютеру», если появится запрос.
3. В Xcode → Settings → Accounts добавь свой Apple Account, если он ещё не добавлен.
4. Выбери синий значок проекта → TARGETS → Podhod → Signing & Capabilities. Оставь Automatically manage signing включённым и выбери свою Personal Team.
5. Если Xcode сообщает, что Bundle Identifier занят, замени `app.personal.podhod` на уникальный, например `app.<твое-имя>.podhod`. Бесплатная учётная запись поддерживает HealthKit.
6. В списке устройств вверху Xcode выбери свой iPhone и нажми **⌘R**.
7. Если Xcode попросит, включи на iPhone **Настройки → Конфиденциальность и безопасность → Режим разработчика** и перезагрузи телефон. При необходимости доверься своему профилю в **Основные → VPN и управление устройством**.

Публикация в App Store не нужна. С бесплатной Personal Team профиль подписи действует 7 дней с выдачи. Для продления используется повторная сборка и установка через ⌘R с той же Team и Bundle Identifier; пока профиль действителен, Xcode может использовать его повторно без сдвига даты. Не удаляй приложение для обычного обновления; перед сменой идентификатора или удалением сохрани JSON-копию.

Подробные шаги для обоих iPhone, установка по Wi‑Fi и варианты через SideStore/AltStore: [Как обновлять подпись](SIGNING_GUIDE_RU.md).

## Возможности

В версии 1.1 добавлены выделение чисел при нажатии, перетаскивание со сворачиванием карточек, замена упражнения, цвет прошлой интенсивности, дроп-сеты и суперсеты. [Как пользоваться новыми функциями](UPDATE_1_1.md).

- Пустая тренировка и запуск программы; 32 встроенных упражнения и 3 редактируемых стартовых шаблона. История при первом запуске пустая.
- Программы с целевыми подходами, весом, повторами, заметками и отдыхом каждого упражнения.
- Собственные упражнения: название, основная и дополнительные мышцы, внешний вес / собственный вес / отягощение / противовес.
- Фактический результат последней завершённой тренировки с упражнением рядом с каждым подходом, независимо от программы. Через меню подхода можно повторить прошлый результат.
- Интенсивность «Легко / Средне / Тяжело», разминочные подходы, добавление, удаление и изменение порядка упражнений и подходов.
- Таймер длительности; автоматический отдых после галочки, изменение на ±15 секунд и пропуск; системное уведомление об окончании отдыха.
- Сохранение после изменений, восстановление незавершённой тренировки, сворачивание и возвращение к ней.
- История и исправление записей; время, объём, рекорды, импорт среднего пульса.
- Профиль, часы тренировок, календарь, рабочие подходы по мышцам за 7/14/30 дней.
- Вес тела, шея, грудь, талия, бёдра, рука, бедро и голень с датами и графиками.
- Экспорт и восстановление JSON-копии через Профиль → Настройки. Перед заменой данных требуется подтверждение.

## Apple Watch и отдых

В этой версии есть **чтение среднего пульса после тренировки**, а не приложение watchOS. Запусти на часах обычную силовую тренировку, после завершения дождись синхронизации с «Здоровьем» на iPhone. В истории «Подхода» открой соответствующую запись и выбери импорт пульса. При первом импорте выдай разрешение на чтение тренировок и пульса.

Импорт сопоставляет тренировку по времени: подходящая силовая/смешанная сессия должна перекрывать не менее 70% обеих записей. Чужие по времени замеры не подставляются, отсутствие доступа или данных не изображается нулевым пульсом. Приложение ничего не записывает в HealthKit.

Собственный экран Apple Watch, отметка подходов на часах и пульс в реальном времени — следующий этап. Реальную синхронизацию HealthKit и звук при заблокированном iPhone необходимо проверить на твоих устройствах.

Разрешение на уведомления запрашивается при начале первой тренировки. Сигнал ставится системным уведомлением и не требует работающего в фоне секундомера. Беззвучный режим, Фокусирование и настройки уведомлений влияют на звук. Время на экране рассчитывается по сохранённым датам и восстанавливается после закрытия приложения.

## Как считаются показатели

- В историю при завершении попадают только отмеченные подходы.
- Объём в кг = внешний вес × повторы, включая разминочные подходы. Для упражнений с отягощением учитывается только дополнительный груз. Собственный вес и противовес не прибавляются к тоннажу.
- Для гантелей вводи **суммарный вес гантелей**, работающих в указанном подходе; для одностороннего упражнения придерживайся одного способа учёта веса и повторов.
- Статистика мышц считает только выполненные рабочие подходы. Основные мышцы и участие дополнительных мышц показаны отдельно; это не физиологическая оценка одинаковой нагрузки на каждую мышцу.
- Рекорды: больше вес или больше повторов при том же весе; для собственного веса — больше повторов. Для противовеса — меньше помощи при равных/больших повторах. Первый результат является исходным и не даёт рекорд. В итогах показывается число упражнений с рекордом.
- Изменение программы не переписывает прошлые тренировки.

## Данные

Журнал находится в Application Support внутри контейнера приложения. Запись атомарная; дополнительно сохраняется предыдущая валидная версия. Резервная копия включает журнал, упражнения, программы, измерения и активную тренировку. Сервер, аналитика использования, аккаунты и автоматическая синхронизация с облаком отсутствуют. HealthKit-данные, скопированные в журнал, попадают и в экспортируемый JSON.

## Разработка и проверка

Проект создан для Xcode 26.6. Системный `xcode-select` на этом Mac указывает на Command Line Tools, поэтому для терминала используется локальная переменная без изменения глобальных настроек:

```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcodebuild -project Podhod.xcodeproj -scheme Podhod \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build
```

Тесты:

```sh
xcodebuild -project Podhod.xcodeproj -scheme Podhod \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO \
  -parallel-testing-enabled NO test
```

`PodhodTests` проверяет вычисления, сохранение/восстановление, снимки программ, таймеры и сопоставление HealthKit. `PodhodUITests` проходит основные пользовательские сценарии в изолированном журнале и сохраняет скриншоты в результаты тестов.

После добавления Swift-файлов проект можно пересоздать: `python3 scripts/generate_project.py`. Генератор не требует установки пакетов. Он сбросит ручные изменения `project.pbxproj`, включая выбранную Team; обычный запуск генератора не нужен. Иконка рисуется из векторных примитивов скриптом `scripts/make_icon.swift`.
