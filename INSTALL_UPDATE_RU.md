# Как установить новую сборку «Подхода» на iPhone (Anna)

Эти шаги устанавливают на телефон приложение из текущего кода проекта, включая новые функции и исправления.

15 сентября 2026 года на iPhone (Anna) установлена и успешно запущена версия **1.1 (сборка 2)**. Перед установкой сохранена резервная копия журнала на этом Mac. Ниже — порядок действий для следующих обновлений.

## На этом Mac

1. Подключи iPhone (Anna) к Mac кабелем и разблокируй экран. Если появится запрос «Доверять этому компьютеру», подтверди его на телефоне.
2. Открой **Finder → Документы → ChatGPT → Приложения → Podhod → Podhod.xcodeproj**. Откроется Xcode. Полный путь: `/Users/admin/Documents/ChatGPT/Приложения/Podhod/Podhod.xcodeproj`.
3. В верхней панели Xcode выбери схему **Podhod**. Рядом находится выбор устройства: выбери **iPhone (Anna)** из списка физических устройств. Пункт **iPhone 17 Pro** в разделе симуляторов запускает приложение на Mac, а не на телефоне.
4. Нажми **▶ Run** вверху слева или **⌘R**. То же действие есть в меню **Product → Run**.
5. Дождись, пока Xcode закончит сборку, установит приложение и откроет «Подход» на телефоне. Во время этого оставь iPhone подключённым и разблокированным.
6. В «Подходе» открой **Профиль → Настройки** и проверь версию. Для обновления с новыми функциями она должна быть **1.1**. Проверь также новое меню **⋯ → Заменить упражнение** в тренировке или конструкторе программы.
7. После успешного запуска кабель можно отключить. Приложение работает самостоятельно.

**Важно:** команда **⌘B / Product → Build** только собирает приложение на Mac. Для установки на iPhone используй **⌘R / Product → Run**.

Xcode устанавливает код, который сейчас лежит в папке проекта. Когда в этот проект добавлены новые функции, повтори шаги выше. Само открытие старого приложения на iPhone не загружает изменения с Mac.

## Тренировки и программы

Устанавливай поверх существующего «Подхода»: **удалять приложение с телефона не нужно**. Сохраняй выбранную команду **Marat Faizov (Personal Team)** и идентификатор **app.personal.podhod** — на этом Mac они уже настроены.

Перед обновлением можно сохранить копию: **Подход → Профиль → Настройки → Сохранить резервную копию → Сохранить в «Файлы»**. Данные на двух iPhone отдельные. Обновление телефона Марата не устанавливает новую версию на iPhone (Anna): для каждого телефона нужно отдельно выбрать устройство в Xcode и выполнить Run.

## Если что-то не получилось

- **iPhone (Anna) отсутствует в списке:** разблокируй его, переподключи кабель и открой **Window → Devices and Simulators**. Дождись, пока Xcode подготовит устройство.
- **Открылся симулятор:** выбери именно **iPhone (Anna)** в верхней панели и снова нажми **⌘R**.
- **Xcode показывает Build Succeeded, но на телефоне старая версия:** убедись, что нажал Run, выбрал Anna и открыл именно этот проект, затем повтори **⌘R**.
- **Сборка не проходит:** открой список ошибок кнопкой с треугольником в левой панели Xcode. Если проблема связана со старой сборкой, выполни **Product → Clean Build Folder (⇧⌘K)**, затем **⌘R**.
- **iPhone просит доверие разработчику:** открой **Настройки → Основные → VPN и управление устройством → профиль разработчика → Доверять**, затем запусти «Подход».

После первоначального сопряжения возможна установка по Wi‑Fi: Mac и iPhone должны находиться в одной сети, а телефон — появиться в Xcode. Выбор устройства и кнопка **⌘R** остаются теми же. При проблемах с сетью используй кабель.
