## Важные правила данных

- Старые подходы не становятся односторонними автоматически; snapshots программ/истории не меняются при редактировании библиотеки.
- Для завершения подхода со сторонами нужны корректные результаты обеих сторон. Объём — сумма нагрузки сторон, мышечный подход — один. Разминка и интенсивность общие на подход. Обычные дроп-сеты сохранены; сочетание сторон с дроп-ступенями не поддерживается и не допускается валидацией.
- Дискомфорт принадлежит конкретному выполнению, не копируется в новую сессию. Отмеченная карточка сохраняется даже без выполненного подхода, если в тренировке выполнен хотя бы один другой подход.
- В сравнении приоритет имеет постоянный ID программы. Для старых данных — безопасное совпадение структуры ≥75%, не совпадение имени. Разное число рабочих подходов или разнонаправленная динамика веса/повторов не объявляются улучшением.
- Уведомление после перерыва считает срок от последнего окончания тренировки; открытие приложения и незавершённая сессия не сбрасывают его. При пустой истории отсчёт начинается с включения.
- Новые поля входят в общий JSON. Восстановление остаётся с подтверждением и атомарной проверенной записью, неизвестная будущая схема отклоняется.

## Ограничения и что требует телефона

Автоматический iCloud-контейнер не поддерживается текущей бесплатной Personal Team: это подтверждено [таблицей возможностей Apple](https://developer.apple.com/help/account/reference/supported-capabilities-ios). Поэтому нет фиктивного переключателя автокопирования. Работает ручной JSON через «Сохранить в Файлы» → iCloud Drive и восстановление с подтверждением. Для автоматического контейнера потребуются подходящая подписка и отдельное разрешение на изменение capabilities/signing.

Live Activity использует системные таймеры и `staleDate`; [ограничения ActivityKit](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities) сохраняются: запуск обычно из foreground, активность до 8 часов, произвольное обновление в фоне не гарантировано. После перезапуска приложение восстанавливает карточку активной тренировки; ручное её закрытие учитывается до завершения текущего процесса.

На физических iPhone ещё нужно проверить экран блокировки и Dynamic Island, возврат по нажатию, сигнал/тактильный отклик, Focus/беззвучный режим и фактическую доставку напоминаний. Симулятор не подтверждает эти условия. HealthKit не менялся; его реальная синхронизация также проверяется на устройстве.

Существующие Bundle ID, Team, entitlements и настройки подписи приложения сохранены. Добавлен отдельный target `PodhodActivity` с той же Team и ID `app.personal.podhod.activity`, без новых привилегированных capabilities. Профили не создавались, приложение на телефоны не устанавливалось, Git push не выполнялся. Номер установленной версии пока не повышался; это рабочие изменения до выпуска новой сборки.
